🎴 中文閃卡 Web Pro (Chinese Flashcards)
這是一個輕量化、免安裝的中文學習工具，專為手機與電腦瀏覽器設計。透過 3D 翻卡互動與語音合成技術，幫助使用者更直覺地背誦單字。

✨ 核心功能
互動翻卡：點擊卡片即可流暢翻轉，查看拼音與字義。

🔊 語音朗讀：內建自動發音功能，支援標準中文（普通話/國語）撥放。

⚙️ 自定義字庫：

隨時新增或刪除單字。

彈性輸入：拼音與意義可選填，僅輸入中文字也能建立卡片。

💾 備份與還原：支援將單字表匯出為 .json 檔案，方便跨裝置同步或備份。

📏 字體縮放：滑動調整字體大小，長輩或手機使用者也能輕鬆閱讀。

🚀 快速開始
將本專案的 index.html 檔案下載到電腦。

直接使用瀏覽器（如 Chrome, Safari）開啟該檔案。

手機使用建議：將檔案上傳至 GitHub Pages、Google Drive 或透過 LINE 傳給自己，即可在手機上隨時練習。

🛠️ 技術說明
純前端架構：僅使用 HTML5, CSS3, 與原生 JavaScript。

資料隱私：所有單字資料均儲存於瀏覽器的 localStorage 中，不會上傳至任何雲端伺服器。

語音技術：使用瀏覽器內建的 Web Speech API。
